Secrets

Two resources carry secret material: the items of a Nomad variable and the secret of an ACL token. This page states where each one appears in a play’s output.

Variables

items is marked no_log, so a value supplied through it is shown as VALUE_SPECIFIED_IN_NO_LOG_PARAMETER wherever it appears in the task’s output, including inside the returned variable. The registered result holds the placeholder, so a value written by one task is read back through the lookup or the _info module.

The diff never carries a value. Each item in before and after is replaced by sha256: and the first twelve hex digits of the SHA-256 of the value, so --diff shows which items were added, removed or changed without showing what they hold.

--- before
+++ after
@@ -2,5 +2,5 @@
   "Items": {
-    "password": "sha256:2bb80d537b1d",
+    "password": "sha256:5e884898da28",
     "username": "sha256:8d969eef6eca"
   },

benemon.nomad.nomad_variable_info returns the items of one variable when path is set, and metadata stubs without items when listing. A registered result of a read by path holds the values and is not masked, so treat such a task as it would be treated with any other secret in a registered variable.

The lookup

benemon.nomad.nomad_variable reads a variable inline, at the point of use, without a registered result or a fact that holds the value afterwards.

- name: Read every item of a variable
  ansible.builtin.debug:
    msg: "{{ lookup('benemon.nomad.nomad_variable', 'db/credentials', namespace='web') }}"

- name: Read one item
  ansible.builtin.template:
    src: app.env.j2
    dest: /etc/app.env
  vars:
    db_password: "{{ lookup('benemon.nomad.nomad_variable', 'db/credentials', key='password', namespace='web') }}"

A variable that does not exist is an error, as is a key the variable does not hold. The lookup takes the same connection options as the modules as keyword arguments and falls back to the same environment variables; it does not see module_defaults.

ACL tokens

Warning

The Nomad API returns a token’s SecretID in every full token document, and the modules pass it on unchanged: the token of every benemon.nomad.nomad_acl_token run, and the tokens of a benemon.nomad.nomad_acl_token_info run that selects a token by accessor ID or name. Every such result is a secret: it appears in the task’s output, in verbose logs, in callback plugins and in a registered variable. Set no_log on these tasks and register their results only when a later task needs the secret.

Diffs never carry the SecretID, and a listing without a selector returns the API’s stubs, which carry no secret.

Because the secret comes back on every run, a play that stores it can converge on any run rather than only on the one that created the token:

- name: Ensure the CI reader token exists
  benemon.nomad.nomad_acl_token:
    name: ci-reader
    type: client
    policies: [read-default]
    expiration_ttl: 24h
  register: token
  no_log: true

- name: Store the secret where the consumer reads it
  benemon.nomad.nomad_variable:
    path: ci/reader-token
    items:
      secret: "{{ token.token.SecretID }}"

Running tasks inside allocations

benemon.nomad.nomad_exec runs a play’s tasks inside a task of a running allocation, over the allocation exec API that nomad alloc exec uses. Nothing is installed in the task and no port is opened: each command travels through the Nomad server to the client node and into the task.

The plugin needs nomadpy with its exec extra, which installs the websockets package:

pip install 'nomadpy[exec]'

Hosts

A host is one allocation and one task in it. Two variables name them:

Variable

Meaning

ansible_nomad_alloc_id

the allocation ID, in full

ansible_nomad_task

the task to run in

ansible_nomad_namespace

the allocation’s namespace; falls back to NOMAD_NAMESPACE

The connection options are the same as everywhere else in the collection, as ansible_nomad_address, ansible_nomad_token and so on, with the same environment fallbacks; see Getting started.

The benemon.nomad.nomad inventory plugin sets the allocation ID and namespace on every allocation host, so a play over its hosts needs only the connection and the task name:

# allocations.nomad.yml
plugin: benemon.nomad.nomad
clients: false
allocations: true

- hosts: nomad_job_web
  connection: benemon.nomad.nomad_exec
  vars:
    ansible_nomad_task: web
  tasks:
    - ansible.builtin.command: cat /etc/hostname

An inventory whose groups each run one task can compose the name instead:

compose:
  ansible_nomad_task: nomad_allocation.TaskStates | first

What the task needs

Commands run through the shell ansible_shell_executable names, /bin/sh by default. Files go in and out over the same channel, as cat reading its stdin or writing its stdout, so the task image needs a POSIX shell and cat. Modules need Python in the task, found through ansible_python_interpreter as on any host; raw commands and raw do not.

Commands run as the task’s user. become is not supported.

ansible_nomad_timeout bounds, in seconds, the wait for the exec connection to open and for each frame of output. Unset, a wait has no bound.

The ACL policy of the token needs alloc-exec on the namespace, and alloc-node-exec as well for tasks on the raw_exec driver.

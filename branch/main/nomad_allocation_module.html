benemon.nomad.nomad_allocation module – Restart, signal or stop a Nomad allocation

Note

This module is part of the benemon.nomad collection (version 0.3.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install benemon.nomad. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: benemon.nomad.nomad_allocation.

New in benemon.nomad 0.2.0

  • Synopsis

  • Requirements

  • Parameters

  • Notes

  • Examples

Synopsis

  • Restart the tasks of a running allocation, send a signal to one of them, or stop the allocation, over the API and without connecting into the task.

  • A restart and a signal always act and always report a change. A stop acts only on an allocation that is still running; one that has finished, or does not exist, reports no change.

Requirements

The below requirements are needed on the host that executes this module.

  • nomadpy >= 0.2.0

Parameters

Comments

Address of the Nomad HTTP API, including the scheme.

Falls back to NOMAD_ADDR, then http://127.0.0.1:4646.

path

Path to a CA certificate file to verify the server against.

path

Falls back to NOMAD_CAPATH.

Path to the client certificate for TLS authentication.

Falls back to NOMAD_CLIENT_CERT.

Path to the private key of client_cert.

namespace

string

Namespace the resource lives in.

Falls back to NOMAD_NAMESPACE, then default.

region

string

Region to send requests to.

Falls back to NOMAD_REGION, then the region of the server answering.

restart

boolean

Restart the task named by task, or every task of the allocation without it.

Choices:

  • false ← (default)

  • true

signal

string

Signal to send to task, such as SIGHUP.

skip_verify

Do not verify the server certificate.

Falls back to NOMAD_SKIP_VERIFY.

Task the restart or the signal applies to. Required with signal.

timeout

Seconds to wait before giving up when wait=true.

Default: 300

Server name to verify the certificate against instead of the host in address.

Falls back to NOMAD_TLS_SERVER_NAME.

ACL token secret sent with every request.

Falls back to NOMAD_TOKEN.

boolean

Wait for the allocation to reach a terminal client status after a stop.

Choices:

  • false

  • true ← (default)

Notes

Note

  • Connection options fall back to the environment variables the Nomad CLI reads, with the same meaning.

  • Enterprise features are not checked client-side. On a Community server the request fails with the server’s own error.

Examples

- name: Restart every task of an allocation
  benemon.nomad.nomad_allocation:
    alloc_id: 8b5e7a4e-2b1d-6f0c-9a3e-0d1f2a3b4c5d
    restart: true

- name: Reload one task's configuration
  benemon.nomad.nomad_allocation:
    alloc_id: 8b5e7a4e-2b1d-6f0c-9a3e-0d1f2a3b4c5d
    task: web
    signal: SIGHUP

- name: Stop an allocation and wait for it to finish
  benemon.nomad.nomad_allocation:
    alloc_id: 8b5e7a4e-2b1d-6f0c-9a3e-0d1f2a3b4c5d
    state: absent

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

allocation

dictionary

The allocation as the Nomad API returns it after the action, with the API’s field names; absent when it does not exist.

Returned: always

eval_id

string

ID of the evaluation a stop created.

Returned: when the allocation was stopped

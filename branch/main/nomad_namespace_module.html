benemon.nomad.nomad_namespace module – Manage a Nomad namespace

Note

This module is part of the benemon.nomad collection (version 0.3.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install benemon.nomad. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: benemon.nomad.nomad_namespace.

New in benemon.nomad 0.1.0

Synopsis

  • Create, update or delete a namespace.

  • Only the options that are set are compared and written; an option left out keeps its current value on the server.

Requirements

The below requirements are needed on the host that executes this module.

  • nomadpy >= 0.2.0

Notes

Note

  • Connection options fall back to the environment variables the Nomad CLI reads, with the same meaning.

  • Enterprise features are not checked client-side. On a Community server the request fails with the server’s own error.

Examples

- name: Create a namespace restricted to the docker driver
  benemon.nomad.nomad_namespace:
    name: web
    description: Web tier
    capabilities:
      enabled_task_drivers: [docker]

- name: Apply a quota to the namespace (Enterprise)
  benemon.nomad.nomad_namespace:
    name: web
    quota: web-quota

- name: Delete the namespace
  benemon.nomad.nomad_namespace:
    name: web
    state: absent

benemon.nomad.nomad_variable lookup – Read a Nomad variable

Note

This lookup plugin is part of the benemon.nomad collection (version 0.3.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install benemon.nomad. You need further requirements to be able to use this lookup plugin, see Requirements for details.

To use it in a playbook, specify: benemon.nomad.nomad_variable.

New in benemon.nomad 0.1.0

Synopsis

  • Return the items of a variable, or one item of it, read inline.

  • A variable that does not exist is an error.

Requirements

The below requirements are needed on the local controller node that executes this lookup.

  • nomadpy >= 0.2.0

Terms

Parameter

Comments

Terms

list / elements=string / required

Paths of the variables to read.

Keyword parameters

This describes keyword parameters of the lookup. These are the values key1=value1, key2=value2 and so on in the following examples: lookup('benemon.nomad.nomad_variable', key1=value1, key2=value2, ...) and query('benemon.nomad.nomad_variable', key1=value1, key2=value2, ...)

Parameter

Comments

address

string

Address of the Nomad HTTP API, including the scheme.

Falls back to NOMAD_ADDR, then http://127.0.0.1:4646.

ca_cert

path

Path to a CA certificate file to verify the server against.

Falls back to NOMAD_CACERT.

ca_path

path

Path to a directory of CA certificates to verify the server against.

Falls back to NOMAD_CAPATH.

client_cert

path

Path to the client certificate for TLS authentication.

Falls back to NOMAD_CLIENT_CERT.

client_key

path

Path to the private key of client_cert.

Falls back to NOMAD_CLIENT_KEY.

key

string

Return only this item’s value instead of the items dict. An item that does not exist is an error.

namespace

string

Namespace the resource lives in.

Falls back to NOMAD_NAMESPACE, then default.

region

string

Region to send requests to.

Falls back to NOMAD_REGION, then the region of the server answering.

skip_verify

boolean

Do not verify the server certificate.

Falls back to NOMAD_SKIP_VERIFY.

Choices:

  • false

  • true

tls_server_name

string

Server name to verify the certificate against instead of the host in address.

Falls back to NOMAD_TLS_SERVER_NAME.

token

string

ACL token secret sent with every request.

Falls back to NOMAD_TOKEN.

Notes

Note

  • When keyword and positional parameters are used together, positional parameters must be listed before keyword parameters: lookup('benemon.nomad.nomad_variable', term1, term2, key1=value1, key2=value2) and query('benemon.nomad.nomad_variable', term1, term2, key1=value1, key2=value2)

  • Connection options fall back to the environment variables the Nomad CLI reads, with the same meaning.

  • Enterprise features are not checked client-side. On a Community server the request fails with the server’s own error.

Examples

- name: Read every item of a variable
  ansible.builtin.debug:
    msg: "{{ lookup('benemon.nomad.nomad_variable', 'db/credentials', namespace='web') }}"

- name: Read one item
  ansible.builtin.debug:
    msg: "{{ lookup('benemon.nomad.nomad_variable', 'db/credentials', key='username') }}"

Return Value

Key

Description

Return value

list / elements=any

The item dictionary of each path, or the value of key in each.

Returned: success
